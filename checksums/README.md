# Checksums

SHA-256 digests of published artifacts.

`wikipedia-es-slice-v0.1.0.sha256` is the digest of `samples/wikipedia_es/slice.jsonl` produced by:

```bash
python3 scripts/fetch_wikipedia_es_slice.py
```

That file is generated, not always stored. Live Wikipedia extracts change; if the hash drifts after a re-fetch, bump the slice version instead of editing this digest.

Auralis pins a mix by name, version, and hash from this directory.
